You are building the full MVP backend + frontend for RecycleLah, a recycling pickup platform with three interfaces: SELLER, COLLECTOR, and ADMIN. The entire system must be mobile-first, responsive, and structured cleanly for future conversion into a mobile app (FlutterFlow or React Native wrapper).

===========================
SYSTEM OVERVIEW
===========================
RecycleLah connects SELLERS who want to recycle items with COLLECTORS who pick up and deliver items to recycling centers. The platform includes:
- Real-time GPS tracking
- Wallet + escrow logic
- Dynamic recycling prices
- Admin oversight
- Mobile-friendly UI

===========================
USER ROLES
===========================
1. SELLER (household or business)
2. COLLECTOR (gig worker)
3. ADMIN (platform owner)

===========================
CORE FEATURES
===========================

1. AUTHENTICATION
- Username + password login
- Role selection: SELLER or COLLECTOR
- Phone number required
- JWT-based auth or Replit Auth
- Store users in database with role field

===========================
ESCROW + WALLET LOGIC
===========================
- Seller must have enough balance to create job
- When collector accepts job:
  - Lock seller’s amount into ESCROW (internal ledger)
- After receipt verification:
  - Release ESCROW:
    - Collector payout
    - Platform commission
    - Seller receives remaining amount (if applicable)
- Wallet top-up uses mock FPX API (ToyyibPay/Billplz placeholder)
- Withdrawal is manual (admin triggers)

===========================
REAL-TIME TRACKING
===========================
- Collector sends GPS coordinates every few seconds
- Seller sees collector moving on map
- Use WebSockets or polling
- Map shows:
  - Seller location
  - Collector location
  - Recycling center location

===========================
RECYCLING CENTER MODULE
===========================
- Hardcode 3–5 centers
- Each center has:
  - Name

  - GPS coordinates

===========================

- E-waste price
